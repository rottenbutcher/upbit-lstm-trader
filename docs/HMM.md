# HMM 비교 설계

## 실행과 결과

Windows에서는 `HMM.cmd`를 더블클릭합니다. 별도 명령은 `python -m upbit_bot.cli train-hmm --compare-lstm artifacts`입니다. HMM 단독 실행은 마지막 옵션을 생략합니다. CPU 학습이며 API 키는 필요하지 않습니다. Python 3.12 환경은 클릭 실행 시 자동 설치됩니다. `hmmlearn`은 선택 의존성이므로 Oracle 런타임 설치에는 추가되지 않습니다.

완료 시 `artifacts/hmm/comparison.html`이 열립니다. `comparison.json`에 날짜·데이터 해시·설정·종목별 수치·참조 LSTM 해시가 기록됩니다. `hmm-model.json`은 정규화 계수, 초기/전이 확률, Gaussian 평균/분산, 상태별 수익률을 JSON으로 저장합니다. 임의 코드를 실행하는 pickle 파일을 불러오지 않습니다. 비교용 결과는 운영 모델 manifest가 아니며 Oracle 패키지의 모델로 선택되지 않습니다.

## 통계적 의미

- 관측: 1봉/12봉 로그수익률, 12봉 변동성, 48봉 기준 거래량 z-score. 미래 값으로 채우지 않는 기존 특징 계산을 사용합니다.
- 모델: 종목마다 별도 3상태 대각 Gaussian HMM. 시간에 따른 잠재 상태 전이와 관측 분포를 학습합니다. 상태 번호에 상승/하락 같은 정답 레이블을 가정하지 않습니다.
- 학습: 정규화는 학습 구간 전체의 유효 관측만 사용합니다. 2,048봉 이하 연속 블록을 시간축 전체에서 균등하게 선택해 최대 60,000봉으로 EM을 적합합니다. 블록마다 독립 시퀀스 길이를 전달하여 떨어진 시점 사이의 가짜 전이를 만들지 않습니다. 이 값은 상한이며 짧은 마지막 블록 때문에 실제 표본은 적을 수 있습니다. `max_fit_rows=0`은 모든 블록을 사용합니다.
- 초기화: 2개 고정 시드, 최대 40회 EM, 학습 우도가 높은 초기화를 채택합니다. 반복 횟수와 수렴 허용치 도달 여부는 저장된 모델의 `attempts`에서 확인합니다. 최대 반복 수 종료를 수렴 보장으로 해석하지 않습니다.
- 예측: `P(state[t] | observations[:t+1])`를 직접 계산합니다. 전체 시퀀스의 Viterbi 또는 forward-backward smoothing을 예측에 사용하지 않습니다. 검증·테스트 관측을 과거부터 차례로 받을 수 있지만 그 구간의 정답으로 모델을 다시 적합하지 않습니다.
- 수익률 대응: 학습 구간의 forward 상태 확률로 다음 봉 시가부터 6봉 뒤 시가까지의 로그수익률을 가중 평균합니다. 경계를 넘는 학습 라벨은 제거하고, 희귀 상태의 추정은 학습 전체 평균 쪽으로 100표본에 해당하는 강도로 축소합니다. 테스트 예측은 현재 상태 확률과 저장된 상태별 기대수익률의 내적입니다.

## 공정한 비교

참조 LSTM의 설정·학습/검증 경계·종목·비용·운용 자금을 사용합니다. HMM 옵션만 현재 설정에서 가져옵니다. 둘 다 기존 `split_indices`의 동일한 유효 봉과 목표 수익률을 사용합니다. LSTM은 ONNX로 동일한 저장 데이터에서 다시 추론하며 과거 보고서 수치를 그대로 복사하지 않습니다. 각 모델의 매수 기준은 동일한 후보와 동일한 검증 선택 규칙으로 정하고 테스트에서 재조정하지 않습니다.

새 LSTM 학습 결과에는 시장별 데이터 시작/끝/행 수/SHA-256이 저장됩니다. 새 봉이 추가돼도 기존 학습 당시 범위만 잘라 사용하며, 그 범위의 값이 달라지면 비교를 중단합니다. 해시가 없는 이전 LSTM은 공통 `data_end`까지의 현재 저장 데이터로 비교할 수 있지만, 최초 학습 데이터와 같다는 보장은 없다는 문구가 표시됩니다. 비교 모드는 다운로드를 수행하지 않습니다.

방향은 `return > 0` 대 `return <= 0`으로 정의합니다. 균형 정확도는 두 클래스 재현율의 평균이며 한 클래스만 존재하면 계산하지 않습니다. 종목별 학습 다수 방향은 학습 라벨에서만 정합니다. 무조건 상승 기준, 예측 수익률 0의 MAE, 실제 수익률 0의 비율을 함께 제공합니다. 높은 정확도가 수수료 후 이익을 뜻하지 않으며, 무거래 수익률 0은 수익성 증거가 아닙니다.

30분 타깃을 5분마다 평가하므로 라벨은 서로 겹칩니다. 따라서 독립 표본을 가정한 단순 이항 신뢰구간이나 통계적 우월성 주장은 제공하지 않습니다. 같은 테스트를 보고 반복 실험한다면 별도의 미사용 기간이나 사전에 정한 walk-forward 검증이 필요합니다. 현재 상위 종목의 생존/선정 편향 및 체결 근사 한계는 LSTM과 같습니다.

## 검증

합성 데이터로 forward 확률과 가능한 상태 경로의 직접 합을 대조하고, 미래 관측/라벨 변경에 과거 예측·학습 파라미터가 변하지 않는지 검사합니다. 추가된 봉과 수정된 봉의 데이터 해시 처리, 동일한 봉의 HMM/LSTM 비교, 기존 LSTM 예측 오차의 재현, HTML/JSON/CSV 생성을 검사합니다. 합성 테스트는 실제 투자 성과 평가가 아닙니다.
